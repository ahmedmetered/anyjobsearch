# anyjobsearch

This file is the discovery entrypoint when the whole repository is cloned
into a skills folder. The canonical workflow lives one level down.

**Read [skill/SKILL.md](skill/SKILL.md) and follow it as the workflow.** The
references it points to are in `skill/references/`, the CV builder is in
`cv/`, and filled examples are in `examples/`. Candidate data never belongs
in this repository; keep it in the candidate's own data folder.
